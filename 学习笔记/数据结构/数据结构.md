# 第二章 线性表

## 2.1 线性表的定义和基本操作

### 线性表Linear List的定义

线性表是具有**相同**的数据类型的n(n>=0)个**数据元素的有限**序列，其中n为表长，当**n=0时**线性表是一个**空表**。
若用L命名线性表，则起一般表示为：
$L=(a_1,a_2,...,a_i,a_{i+1}，...，a_n)$

```
相同数据类型：每个数据元素所占空间一样大。

序列： 代表线性表是有次序的。

有限：限制数据元素的数量。

ai是线性表中的“第i个”元素线性表中的位序

a1是表头元素；an是表尾元素

除第一个元素外，每个元素有且仅有一个直接前驱;
除最后一个元素外，每个元素有且仅有一个直接后继

注意：定义数组时，数组下标从0开始

```

### 线性表的基本操作

InitList(&L):初始化表。构造一个空的线性表L，分配内存空间。
DestroyList(&L):销毁操作。销毁线性表，并释放线性表L所占用的内存空间。

ListInsert(&L,i,e):插入操作。在表L中的第i个位置上插入指定元素e。
ListDelete(&L,I,&E):删除操作。删除表L中第i个位置的元素，并用e返回删除元素的值。

LocateElem(L,e):按值查找操作。在表L中查找具有给定关键字值的元素。
GetElem(L,i):按位查找操作。获取表L中第i个位置的元素的值。

其他常用操作：
Length(L):求表长。返回线性表L的长度，即L中数据元素的个数。
PrintList(L):输出操作。按前后顺序输出线性表L的所有元素值。
Empty(L):判空操作。若L为空表，则返回true,否则返回false。

基本操作：创建、销毁、增删改查

## 2.2顺序表的定义和基本操作

### 顺序表的定义

顺序表是用**顺序存储**的方式实现线性表顺序存储。把**逻辑上相邻**的元素存储在**物理位置也相邻**的存储单元中，元素之间的关系由存储单元的邻接关系来体现。

折线性表第一个元素的存放位置是LOC(L)。
第二个数据元素存放位置为：LOC(L)+数据元素大小;
第三个数据元素存放位置为：LOC(L)+2*数据元素大小；
推广至第N个数据元素存放位置：

$LOC(L)+n*数据元素大小$

数据元素计算方式：
C语言：

``` c
//sizeof(ElemType);
//例如：
sizeof(int);

float a;
sizeof(a);

//也可以计算结构体数据元素的大小

typedef struct 
{
    int num;
    int people;
} Customer;

sizeof(Customer)
```

### 顺序表的实现--静态分配

``` c
#define MaxSize 10          //宏定义最大长度
typedef struct
{
    ElemType data[MaxSize]; //用静态的“数组”存放数据元素
    int length;             //顺序表的当前长度
}SqList;                    //顺序表的类型定义（静态分配方式：指在程序运行之前就已经分配好空间大小）

```

静态分配：给各个数据元素分配连续的存储空间，大小为
$MaxSize*sizeof(ElemType)$

用C语言实现：
**定义顺序表和初始化顺序表**
``` c
#include <stdio.h>
/// <summary>
/// 顺序表定义
/// </summary>
#define MaxSize 10
typedef struct Sqlist
{
	int data[MaxSize];
	int length = 0;
}Sqlist;

//基本操作：创建（初始化）一个顺序表

void InitialList(Sqlist &L)
{
	for (int i = 0; i < MaxSize; i++)
	{
		L.data[i] = 0;//初始化为0
		L.length = 0;
	}
}

//在main函数中调用

int main()
{
	Sqlist L;
	InitialList(L);

	//查看当前数组初始化的状态
	for (int i = 0; i < MaxSize; i++)
	{
		printf("%d ", L.data[i]);
	}
	return 0;
}
```

### 顺序表的实现--动态分配

``` c
#define InitSize 10     //顺序表初始长度
typedef struct SeqList  
{
    ElemType *data;     //指数动态分配数组的指针
    int MaxSize;        //顺序表的而最大容量
    int length;         //顺序表的当前长度
}                       //顺序表的类型定义（动态分配方式 ：在程序运行时也可以分配空间）
```

C语言：使用malloc函数动态申请和释放内存空间,malloc会返回一个指针，需要强制类型转化为数据元素类型指针才可对数据元素进行操作。

$L.data=(ElemType*)malloc(sizeof(ElemType)*InitSize);$
